Blog Content Generation API (POST /api/blogs/generate)

Generate and publish complete SEO articles on demand from any external backend, CMS webhook, or agent.

cURL Request Example

curl -X POST http://localhost:4000/api/blogs/generate \
  -H "Content-Type: application/json" \
  -d '{
    "topic": "Essential Daily Dental Hygiene Routines",
    "tone": "Educational",
    "length": "Standard (~1,000 words)",
    "businessName": "Apex Dental",
    "businessIndustry": "Dentistry"
  }'

JavaScript (fetch) Example

const res = await fetch('http://localhost:4000/api/blogs/generate', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    topic: 'Healthy teeth daily routine',
    tone: 'Professional',
    length: 'Standard'
  })
});
const data = await res.json();
console.log('Article Title:', data.blog.title);
console.log('Article Body:', data.blog.body);
